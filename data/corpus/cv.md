JSON reference library, a reference-based explanation, and recommended actions.
A shared graph supports Streamlit and React/FastAPI interfaces. Unknown codes use a
safe core fallback; the API rejects unsupported codes. The active graph does not
call an LLM. See the separate project write-up for current GitHub implementation details.

Rainbow Advertising - Billboard Management Platform (Django, SQLite, Tailwind CSS).
A web application for billboard inventory, client bookings, and payment records.

The checked version uses SQLite and has a demonstration PDF endpoint, not CSV export.
See the separate project write-up for implementation details and limitations.

VisionVoice — Image Captioning & Audio Generation (CNN-LSTM, Tacotron 2, WaveNet).

Real-Time Chat Application (Django Channels, PostgreSQL, WebSockets). A real-time

Weather Forecasting (Python, LSTM, TensorFlow). A time-series forecasting prototype
